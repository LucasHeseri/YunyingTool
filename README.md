# YunYingTool

运营工具集 — 桌面端图片加工工具。

## 功能

- **WalletKit机模**：图片合成到卡片/票券 SVG 机模
- **票券**：登机牌 / 门票模板，独立数据，可换背景色、上传海报
- **logo处理**：宫格图 + 圆形 logo
- **图片压缩**：等比例缩放
- **裁切卡券**：图片裁切
- **借贷模板**：金融卡片

## 使用方式

浏览器打开 `图片加工工具.html`，无需安装依赖。  
单文件版：`dist.html`（运行 `./build.sh` 生成）。

## 开发

```bash
# 日常开发
编辑 图片加工工具.html + 各 .js 模块

# 发布前构建单文件版
./build.sh
```
